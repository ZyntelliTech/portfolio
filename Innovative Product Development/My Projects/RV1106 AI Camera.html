System composition

The system block diagram is shown below. The main control chip is the RV1106, the SDK uses a modified luckfox-pico SDK, and the graphics library uses LVGL. The Wi-Fi interface uses the SDIO interface and the RTL8723BS. The screen uses a 2.4-inch touch screen, and the storage medium can be an SD card or the onboard NAND Flash. For details, see the schematic diagram.

Functional Description

  1. The product can detect faces, recognize objects, track movement, and trigger automated actions based on visual inputs.
  1. The LCD uses a 2.4-inch screen, SPI ST7789V, touch is IIC FT6336U, the touch screen model is P024C128-CTP.
  1. The LVGL menu can add content by itself according to the paradigm of the warehouse code.
  1. The small TV function is just a demonstration of ffmpeg for now.
  1. AI chat uses WebSocket to communicate with the server (your computer). Since RV1106 has a single-core A7 and the computing power is insufficient, the relevant model reasoning of AI chat is placed Python server on the client.
  1. The intent understanding this is the task of using Google's FastText model to classify text.
  1. The power supply is currently only Type C, and batteries can be added later to increase space freedom.

Software Introduction

The device was developed utilizing the LuckFox-Pico SDK. The main controller uses the RV1106 processor, equipped with a single-core 32-bit CPU Cortex-A7 and rich interface expansion, making it suitable for AI deployment, computer vision, IoT devices, smart audio, smart displays, etc.

The overall software framework is shown in the figure below:

  1. The UI layer uses LVGL, and the PageManager still uses a stack to manage multiple pages. Compared to the previous projects, this project's PageManager is more complete, allowing you to directly register and query pages using char characters, making management more convenient than using variables directly.
  1. In the UI layer, the logic of creating an app is to start a thread to run the app after entering the page, either the main thread or the UI thread.
  1. The business layer is the specific functions actually implemented by these apps, such as the the AI camera and yolov5 reasoning, smart audio, translate, etc. The results of these operations can be displayed in the UI layer, that is, the UI layer interacts with the specific business layer.
