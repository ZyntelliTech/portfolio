Project Overview

The client specializes in advanced UVC and ballast monitoring solutions that enhance air quality and disinfection safety. For this project, the client provided custom hardware, and my responsibility was to design and implement the embedded firmware, along with seamless integration into AWS IoT for secure, scalable cloud connectivity.

My Role & Contributions

  • Firmware Development (ESP32-S3)
    • Implemented firmware for data acquisition, device control, wireless communication (Wi-Fi, Bluetooth LE), and fault diagnostics.
    • Built drivers and system logic using ESP-IDF and FreeRTOS.
    • Enabled secure connectivity to the cloud with MQTT and AWS IoT Core.
  • AWS IoT Cloud Integration
    • Integrated with AWS IoT Core for device provisioning, messaging, and shadow management.
    • Configured secure authentication and data pipelines for telemetry.
    • Implemented OTA (Over-the-Air) updates for remote firmware upgrades.
  • Flutter Mobile App Development
    • Designed and developed a cross-platform mobile app (iOS & Android) using Flutter.
    • Implemented real-time data visualization of UVC and ballast performance.
    • Built features for device control, status monitoring, and alerts.
    • Integrated secure AWS IoT communication via MQTT for seamless cloud-device-app interaction.
  • System Reliability & Security
    • Added device-level diagnostics and remote troubleshooting features.
    • Ensured data encryption and secure authentication between hardware, cloud, and mobile app.

Key Technologies

  • Hardware: ESP32-S3, UVC & ballast sensors
  • Firmware: ESP-IDF (C/C++), FreeRTOS
  • Cloud: AWS IoT Core, MQTT, Device Shadows, OTA updates
  • Mobile App: Flutter (Dart), AWS IoT integration, Bluetooth LE, cross-platform (iOS & Android)

Results & Impact

  • Successfully delivered two production-ready products (AC-Lynx and Dose-EZ) with end-to-end IoT capability.
  • The Flutter app provides customers with a simple and intuitive interface for managing devices in real time.
  • Enabled the client to scale product deployment quickly while maintaining robust monitoring and security.
