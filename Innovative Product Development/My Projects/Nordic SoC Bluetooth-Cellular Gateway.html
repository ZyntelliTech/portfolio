Project Overview

Designed and developed a Bluetooth–cellular IoT gateway that connects distributed Bluetooth mesh sensors to the cloud. The gateway scans real-time sensor data, transmits it over LTE-M/NB-IoT, and provides location and environmental monitoring features.

The solution demonstrates end-to-end IoT system design — from embedded hardware and firmware to cloud connectivity and data visualization.

System Architecture

  1. Bluetooth Mesh Sensors → Gateway (nRF52840)
  1. Gateway (nRF9160):
    • Aggregates mesh data.
    • Adds GNSS location + onboard sensor data.
    • Sends payload securely to AWS IoT Core.
  1. AWS IoT Core → Data Pipeline (Lambda → DynamoDB).
  1. User Dashboard: Real-time monitoring of sensor + device status.

Key Features

  • Multi-protocol support:
    • nRF52840 for Bluetooth Mesh sensor scanning.
    • nRF9160 for cellular communication (LTE-M/NB-IoT) and GNSS tracking.
  • Cloud Integration:
    • Secure MQTT/TLS communication with AWS IoT Core.
    • Real-time sensor data storage, processing, and visualization.
  • Onboard Sensing:
    • Integrated temperature and humidity sensor.
    • Battery level monitoring for power management.
  • Mobility & Tracking:
    • GNSS support for real-time geolocation tracking.
    • Battery-powered for portable deployment.

Technology Stack

  • Hardware: Nordic nRF52840, nRF9160, GNSS receiver, Temp/Humidity sensor.

  • Firmware:
    • Zephyr RTOS on both SoCs.
      • nRF52840 (Bluetooth Mesh Controller)
        • Scans and aggregates sensor advertisements from a Bluetooth Mesh network.
        • Packages data and communicates with the nRF9160 via UART/SPI IPC.
        • Runs a lightweight Zephyr RTOS thread model.
      • nRF9160 (Cellular + Cloud Controller)
        • Manages LTE-M/NB-IoT connection with AWS IoT Core.
        • Handles secure MQTT/TLS communication.
        • Integrates GNSS for real-time location tracking.
        • Reads onboard environmental sensors (Temp/Humidity, Battery).
        • Performs data aggregation and power optimization.
    • Security
      • TLS 1.2 with hardware crypto acceleration on nRF9160.
      • Secure key storage using ARM TrustZone features.
      • Over-the-air (OTA) firmware update support enabled for nRF9160.
    • Power Management
      • Implemented deep sleep modes on both MCUs.
      • LTE-M/NB-IoT connection uses PSM (Power Saving Mode) and eDRX for reduced idle consumption.
      • GNSS runs in duty-cycled mode, acquiring fixes at configurable intervals.
      • ADC sampling optimized for low-power periodic battery monitoring.
      • Estimated runtime: several days on a 2000 mAh battery (depending on reporting interval).
  • Cloud:
    • AWS IoT Core integration using MQTT over TLS 1.2.
    • Device uses X.509 certificates provisioned during setup.
    • AWS Lambda & DynamoDB for data processing and storage.
    • Amazon QuickSight / custom dashboards for visualization.
