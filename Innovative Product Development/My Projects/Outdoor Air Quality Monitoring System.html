Project Description

Our team developed a complete end-to-end Air Quality Monitoring solution — from custom hardware and embedded firmware to cloud infrastructure and mobile applications. This robust system enables organizations to track and analyze environmental data with precision, reliability, and ease of access.

The device is housed in a rugged IP68 waterproof enclosure with solar-powered battery management, making it suitable for continuous outdoor deployment in any environment. It monitors a comprehensive range of parameters including Particulate Matter (PM1, PM2.5, PM10), SO₂, NO₂, O₃, H₂S, NH₃, CO, CH₄, CO₂, TVOC, temperature, humidity, and noise levels (30–130 dB with ±1 dB accuracy). An integrated GPS module ensures precise geo-tagging of all collected data.

Overview

  • Outdoor-Ready: IP68 waterproof enclosure with solar + battery power management.
  • Comprehensive Monitoring: PM1, PM2.5, PM10, SO₂, NO₂, O₃, H₂S, NH₃, CO, CH₄, CO₂, TVOC, temperature, humidity, and noise (30–130 dB, ±1 dB).
  • Precision Tracking: Built-in GPS for accurate geo-location of data.
  • Seamless Connectivity: RS485, Wi-Fi, 4G LTE, LoRa, and Ethernet for reliable communication.

Our Contributions

1. Hardware Engineering

  • Custom ESP32-S3 board design

  • 4G LTE (Quectel), LoRa (SX1262), Ethernet, SD storage

  • Multiple Gas and Environment Sensors

  • Solar charging + advanced power management

2. Firmware Development

  • ESP-IDF 5.0 with FreeRTOS
  • Real-Time Data Acquisition: Continuous collection and processing of data from multiple air quality, gas, temperature, humidity, and pressure sensors over UART and I2C interfaces
  • Connectivity Integration:
    • LoRaWAN (SX1262) for long-range, low-power communication.
    • GSM/4G LTE (Quectel) for mobile data transmission.
    • Ethernet for stable, high-bandwidth applications.
    • GPS for geo-tagging environmental data.
  • Power Optimization: Custom low-power management routines to maximize battery and solar efficiency in continuous outdoor deployments.
  • Over-the-Air Updates (OTA): Secure remote firmware updates, reducing maintenance costs and enabling scalability across large device fleets.
  • Robust RTOS Design: Multi-threaded task handling for sensor acquisition, communication stacks, storage, and power management running in parallel with priority scheduling.

3. Cloud & Server Development

  • AWS IoT Core Integration: Each device connects securely via MQTT/REST, ensuring reliable real-time communication between the field and the cloud.
  • Lambda Functions: Event-driven serverless computing for processing incoming data, triggering alerts, and forwarding information to storage and analytics pipelines.
  • Data Storage: Long-term sensor data securely stored in Amazon S3, with structured data pipelines for reporting and analysis.
  • Fleet Management: Centralized control to register, configure, monitor, and update thousands of devices at scale.
  • AI/ML with SageMaker: Leveraging machine learning models for anomaly detection, predictive analytics, and actionable insights on air quality trends.
  • Secure OTA Deployment: Integration between IoT Core and S3 for safe, encrypted firmware updates pushed directly to devices in the field.
  • Scalability & Reliability: Architecture designed to handle large-scale, distributed deployments with minimal downtime and cost efficiency.

4. Mobile & Web Applications

Mobile Applications (React Native)

  • Developed in React Native for iOS and Android with a single codebase.
  • Real-Time Monitoring: Live visualization of air quality metrics (PM, gases, CO₂, TVOC, noise, temperature, humidity) with intuitive graphs and charts.
  • GPS-Integrated Mapping: Users can view environmental data tied to precise locations, enabling hotspot detection and area-wise analysis.
  • Push Notifications & Alerts: Immediate warnings when thresholds are exceeded (e.g., hazardous PM2.5 or toxic gas spikes).
  • Historical Data & Trends: Interactive data history with filtering by time, location, and parameter for long-term analysis.
  • Device Management: Add, configure, and monitor multiple deployed sensors in a single interface.
  • Offline Support: Local data caching with auto-sync when connectivity is restored.
  • Customizable UI/UX: Flexible dashboards with options for personalized views.

Web Dashboard

  • Comprehensive Visualization: Rich charts, graphs, and maps powered by real-time cloud data.
