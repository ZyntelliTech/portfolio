The Wash Management System

  • Remotely monitor the status of up to 24 individual inputs via the internet. Use any web browser to control the Anztec ASM-1000 with the software application that’s embedded into it. Check levels and status either locally or remotely.
  • The ASM-1000 has fully isolated inputs for connection to devices such as coin and token acceptors or wash start signals. Channels can also be configured as triggers to warn of fault conditions or alarms.
  • Configure users with different privilege levels depending on their roles and duties. Download performance data to any spreadsheet application.
  • Receive reports and alerts via email and/or Pushover phone app.
  • Rolling daily, weekly and monthly totals for each input allow for performance tracking of individual pieces of equipment. Real-time current totals show exactly what should be present in cashboxes at any given time.
  • View the status of the inputs locally via the front panel indicators on the ASM-1000 for instantaneous feedback on individual inputs. Additional configuration information is displayed via an easy-to-read LCD.

Software Development

The embedded system was developed utilizing the Torizon OS based on the Yocto Project.

Refer to this link: https://developer.toradex.com/hardware/colibri-som-family/modules/colibri-imx7/

Hardware Design

  1. Main Board
  • Toradex Colibri iMX7 SoM
  • Touch Screen interface, Camera Interface, Audio Module
  • Peripheral device interface for Washing machines, Door Switches, Level Sensors, and Climate controllers
  • RS232 Custom Module Slots * 4 pcs
  • Dual Ethernet, Dual USB, SD Card, LED Indicators, Power Module,

  1. Display Board
  • Video Sub-Board For Kyocera TCG121WXLRVNN-AN35 12.1" LCD Panel And Zytronic ZXY100-S-OFF-32 (Serial) Or ZXY100-U-OFF-32 (USB) Touch Screen Controller.
  • The LVDS output connector is configured to use a standard cable with Kyocera part number OAI-80038AA-2009-A. Documentation for this cable, however, shows it to be numbered in the reverse direction to the PCB-mounted headers. Further investigation is required to determine compatibility.
  • The original LVDS connector listed in Kyocera documentation is I-PEX 20186-020E-11F. Direct equivalent is JAE FI-S20P-HFE as used in this circuit.

  1. Camera & Audio Board
  • Used TI TPA3128D2DAPR audio amplifier, microphone, and two speakers.
  • USB camera and Ambient light sensor

  1. BackBoard
  • Second Ethernet for 100M and 1GB modes
  • Relay channels for the wash machine outputs
  • ADT7490 Remote Thermal Monitor and FAN Controller for multiple FANs
  • Input channels for the wash machine level sensors
  • Door Switch Inputs
