Project Overview

Designing modern Human-Machine Interfaces (HMIs) on embedded systems requires more than just UI creativity—it demands tight integration between software frameworks and hardware behavior. In this project, we developed a high-performance HMI controller using an ESP32-S3 and a 5-inch 480×800 display, leveraging LVGL and SquareLine Vision.

While the design phase was straightforward, deploying a portrait-oriented interface on real hardware introduced challenges that required deep system-level understanding and custom engineering solutions.

This HMI solution was built with a focus on performance, responsiveness, and industrial usability:

  • Platform: ESP32-S3
  • Display: 5-inch TFT (480×800)
  • Graphics Framework: LVGL
  • UI Design Tool: SquareLine Vision
  • Development Environment: PlatformIO

The UI was visually designed in SquareLine Vision and exported into LVGL-compatible code, enabling a rapid transition from concept to firmware.

Challenge 1: Portrait Mode on Real Hardware

SquareLine Vision provides built-in support for portrait layouts, and the interface rendered perfectly in simulation. However, once deployed to the physical device, the display orientation did not match the expected layout.

What happened:

The discrepancy came from a gap between:

  • Software-level UI rotation (handled in the design tool)
  • Hardware-level display orientation (controlled by the LCD driver)

Solution:

We addressed this by adjusting the display driver configuration to rotate the screen at the hardware level. Once aligned, the UI rendered correctly in portrait mode with proper proportions and layout.

Challenge 2: Touch Input Misalignment

After fixing the display orientation, a second issue emerged—touch inputs were no longer aligned with the visual interface.

Symptoms:

  • Touch points triggered incorrect UI elements
  • Axes appeared swapped or inverted
  • User interaction became unreliable

Root cause:

The touch controller continued reporting coordinates in its native orientation, which no longer matched the rotated display output. This created a mismatch between visual elements and input detection.

Solution: Intelligent Coordinate Mapping

To resolve this, we implemented a coordinate transformation layer within the LVGL input driver. This ensured that all incoming touch data was remapped to match the rotated display orientation before being processed by the UI.

This approach allowed us to:

  • Maintain accurate touch interaction
  • Preserve UI consistency
  • Avoid modifying the core UI design

Final Outcome

With both display and touch layers properly aligned, the system achieved:

  • Reliable portrait-mode rendering (480×800)
  • Accurate and responsive touch interaction
  • Smooth performance on ESP32-S3
  • A production-ready HMI controller suitable for machine integration

Conclusion

Developing a portrait-mode HMI on embedded hardware is not just a UI task—it requires careful coordination across multiple system layers. By combining ESP32-S3 performance, LVGL’s flexibility, and custom driver-level adjustments, we successfully delivered a robust and responsive HMI solution ready for industrial deployment.
